# Projeto Node.js - Catálogo de Filmes

## 📌 Descrição
Atividade prática de Node.js para treinar:
- Lógica e manipulação de dados em JavaScript (ES6+)
- Modularização com CommonJS
- Gerenciamento de projeto com NPM

## 🚀 Funcionalidades
1. Catálogo de filmes com informações: id, título, gênero, ano e status de assistido.
2. Funções implementadas:
   - **Filtrar não assistidos** (`filter`)
   - **Mapear títulos em maiúsculas** (`map`)
   - **Buscar por ID** (`find`)
3. Modularização:
   - Funções separadas em `funcoes.js`
   - Importadas e utilizadas em `index.js`
4. Execução com NPM:
   - Script `start` configurado para rodar com `node --watch`

## 📂 Estrutura do Projeto
meu-projeto-node/
│
├── src/
│   ├── index.js
│   └── funcoes.js
├── package.json
└── README.md

## ▶️ Como executar
No terminal:
`npm run start`
